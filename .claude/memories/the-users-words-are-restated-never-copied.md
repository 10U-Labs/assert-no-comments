# The user's words are restated, never copied

Nothing the user writes is recorded word for word, anywhere. A memory, an issue
title or body, a commit message, a task subject, a feedback draft and a session
summary all carry the user's point in fresh words, with no quotation marks
around the user's sentences and no unquoted copy of them either.

**Why:** the user does not want their own wording kept on record. A paraphrase
carries the rule just as well, and the memories, issues and history stay free
of it.

**How to apply:** before writing down a correction or an instruction, restate
it as the rule it sets, in the record's own terms. A tool or template that asks
for the user's words quoted, such as a feedback draft's field for what the user
said, gets a paraphrase marked as one. A name the user gives, of a file, label,
term or command, stays as it is, since keeping it is not quoting the sentence
around it.
